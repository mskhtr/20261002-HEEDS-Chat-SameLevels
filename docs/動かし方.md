# 動かし方

セットアップが終わったあと、チャットを開いて結果を確認する手順です。

環境の作り方は [セットアップ.md](セットアップ.md)。概要は [README.md](../README.md) です。

コマンドは **Windows PowerShell** に貼ってください。コマンドプロンプトでは実行しないでください。PowerShell の開き方は [セットアップ.md](セットアップ.md) にあります。

## 起動

セットアップ済みなら、エクスプローラで **`start.bat` をダブルクリック**しても起動できます。

コマンドで起動する場合は、先にプロジェクトフォルダへ移動します。

```powershell
cd C:\Users\masaki\Documents\python-projects\20261002_HEEDS-Chat-SameLevels
.\.venv\Scripts\python.exe run_app.py
```

`http://localhost:8000` を開きます。`chainlit run app.py` は使わないでください。

チャットの前に、プログラム設定と HEEDS の実名が一致するか確認できます（解析はしません）。手順は [07_設定チェック.md](07_設定チェック.md) です。

停止は、`start.bat` または PowerShell のウィンドウで Ctrl+C です。ブラウザを閉じただけではサーバーは止まりません。

## チャットでやること

1. 開始時に付く `sample.csv` をダウンロードする
2. 振る変数の行を記入する。行は何行でもよく、`width2` のような名前も足せる
3. 記入した CSV をチャットに添付する
4. 開始画面の表にある言葉を送る。同梱時の例は `衝突安全を確認したい。` と `NVHを確認したい。`
5. 「これで合っていますか？」と返るので、試験名と変数の範囲を見る
6. 合っていれば `はい` と送る。そこで HEEDS が動く
7. 範囲を変えるときは CSV を直して再アップロードする。前の「はい」は、新しい CSV には効かない

要件だけ、または CSV だけでは先に進まず、足りない方を聞いて止まります。両方送ると、解析の前に HEEDS の変数名と個数を照合し、違うときはチャットに出します。照合がずれていても、プログラムはそこで強制停止はせず、確認文を続けて出します。名前が違うまま `はい` と返すと、実行の段階で失敗します。

開始画面の表と、入力欄の上の短いボタンは、`heeds/catalog.yaml` の `label` から作っています。表に書いてある言葉が、いま受け付ける言葉です。

## 確認文に必ず入るもの

- どの設計要件として実行するか
- 試験の日本語名と試験 ID
- CSV の各変数について、名前・下限・初期値・上限・刻み
- 最後の「これで合っていますか？」

この文は AI が書いていません。`heeds/plan.py` がカタログと CSV から組み立てます。

## つまずき

| 症状 | 対処 |
| --- | --- |
| 画面が真っ白 / `NoEventLoopError` | `run_app.py` で起動し直す（`chainlit run app.py` は使わない） |
| 要約だけ失敗し「結果は下の表です」と出る | `.env` の API キー、エンドポイント、デプロイ名を確認する。表が出ていれば HEEDS 自体は終わっている |
| 言葉を書いても「何を確認したいか」と聞き返される | 開始画面の表、または `catalog.yaml` の `label` / `aliases` にある言葉で書く |
| `はい` と送っても実行されない | 直前が確認文であること。文に「変更」「衝突」など要件や変数の語が混ざると同意にしません |
| HEEDS が動かない / Study や変数が見つからない | 先に [07_設定チェック.md](07_設定チェック.md)。名前の約束は [06_HEEDSファイルを作るとき.md](06_HEEDSファイルを作るとき.md) |
| 表が空・出力が取れない | [04_SPEC.md](04_SPEC.md) の「既知の限界」と、`runs/<時刻>/heeds_stdout.txt` |

Python の版、仮想環境、`pip` で止まったときは [セットアップ.md](セットアップ.md) の「つまずき」です。HEEDS 接続そのもののつまずきは [05_HEEDS接続.md](05_HEEDS接続.md) の「よくあるつまずき」です。
