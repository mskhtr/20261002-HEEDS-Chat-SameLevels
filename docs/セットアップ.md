# セットアップ

Python の仮想環境を作り、ライブラリを入れ、`.env` に Azure OpenAI と HEEDS のパスを書くまでの手順です。

概要は [README.md](../README.md)。書いたあとにチャットを開く手順は [動かし方.md](動かし方.md) です。各設定項目の意味は [03_変数と設定.md](03_変数と設定.md) です。

## 必要なもの

| 項目 | 要件 |
| --- | --- |
| OS | Windows |
| エディタ | Visual Studio Code（VS Code）を推奨 |
| Python | **3.12**（複数版が入っていても、仮想環境は必ず `py -3.12` で作る） |
| AI | **Azure OpenAI**（実行後の要約。試験の選択には使わない） |
| HEEDS | HEEDS\|MDO のインストールと、使う `.heeds` プロジェクト |

| 用途 | コマンド |
| --- | --- |
| 入っている版を一覧 | `py -0p` |
| 仮想環境を **3.12** で作る | `py -3.12 -m venv .venv` |
| 仮想環境の Python | `.\.venv\Scripts\python.exe` |

API キーと HEEDS パスは `.env` だけに書きます。ひな形の `.env.example` には本物のキーを書かないでください。

## 使う画面は PowerShell（コマンドプロンプトではない）

この手順のコマンドは、すべて **Windows PowerShell** 用です。

| 名前 | 見分け方 | この手順での扱い |
| --- | --- | --- |
| **PowerShell** | スタートメニューで「Windows PowerShell」または「PowerShell」と検索して開く。窓のタイトルや先頭に `PS` と出ることが多い | **こちらを使う** |
| コマンドプロンプト（cmd） | 「コマンドプロンプト」や `cmd.exe`。先頭が `C:\...>` だけで `PS` が無いことが多い | **使わない**（書き方が違い、同じコマンドで失敗しやすい） |

開き方の例:

1. キーボードの Windows キーを押す
2. `powershell` と入力する
3. **Windows PowerShell** を選んで開く

以降の手順のコマンドは **PowerShell** にコピーして Enter してください。

うまくいったか確認しながら、**1つずつ**進みます。

## 1. フォルダに移動する

```powershell
cd C:\Users\masaki\Documents\python-projects\20261002_HEEDS-Chat-SameLevels
```

- `cd` … 「このフォルダに移動する」コマンドです
- パスが違う場合は、自分の PC 上の実際のフォルダに書き換えてください
- 成功すると、プロンプトの前のパスがこのフォルダになります

## 2. 入っている Python の版を確認する

```powershell
py -0p
```

- Windows の Python ランチャーが、インストール済みの版を一覧表示します
- 出力のどこかに **3.12** があることを確認してください（例: `-3.12-64`）
- 3.12 が無い場合は、先に [python.org](https://www.python.org/downloads/) などから Python 3.12 を入れてからやり直します
- 3.11 や 3.14 など別の版だけがある場合も、この手順では使いません。**3.12 を入れて**から次へ進みます

## 3. 仮想環境（専用の Python 箱）を 3.12 で作る

```powershell
py -3.12 -m venv .venv
```

- `py -3.12` … **3.12** の Python を使う、という意味です
- `-m venv` … 「仮想環境を作る」機能を動かします
- `.venv` … このプロジェクト専用の箱のフォルダ名です
- 初回は少し待ちます。終わると `.venv` フォルダができます
- **すでに `.venv` がある場合:** 中身が 3.12 以外のときがあるので、消してから作り直すか、次の手順 4 で版を確認してください

## 4. 仮想環境の Python が 3.12 か確認する

```powershell
.\.venv\Scripts\python.exe -V
```

- 期待する表示例: `Python 3.12.x`
- `.\.venv\Scripts\python.exe` … 「箱の中の Python」を直接指定しています
- `3.12` でなければ、手順 3 をやり直してください

## 5. pip（ライブラリを入れる道具）を新しくする

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
```

- 警告が出ても、最後にエラーで止まらなければ次へ進んで大丈夫なことが多いです

## 6. 必要なライブラリを入れる

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

- `-r requirements.txt` … 一覧に書いてある部品を全部入れます
- 入るものは Chainlit（チャット画面）、PyYAML（カタログ読み込み）、LangChain の OpenAI 接続（実行後の要約）です
- ネット接続が必要で、数分かかることがあります
- 途中で赤文字の `ERROR` が出て止まったら、そのメッセージを控えて手順を見直してください

## 7. 設定ファイル `.env` を作る

```powershell
copy .env.example .env
```

- `.env.example` は記入例のひな形です（Git に含まれます）
- `.env` は実際に使う設定です（秘密情報を書くので Git には上げません）
- コピーしたあと、VS Code で **`.env`** を編集します

## 8. `.env` に Azure OpenAI と HEEDS を書く

```dotenv
LLM_PROVIDER=azure
AZURE_OPENAI_API_KEY=ここにキー
AZURE_OPENAI_ENDPOINT=https://ここにリソース名.openai.azure.com/
AZURE_OPENAI_DEPLOYMENT=gpt-4o
OPENAI_API_VERSION=2024-10-21
HEEDS_EXE=C:/Program Files/Siemens/HEEDS/2504/HEEDSMDO.exe
HEEDS_PROJECT_PATH=C:/Users/masaki/Documents/python-projects/20261002_HEEDS-Chat-SameLevels/HEEDS_PROJECT/MyProject.heeds
HEEDS_TIMEOUT_SEC=3600
```

| 項目 | 意味（かんたん） |
| --- | --- |
| `LLM_PROVIDER=azure` | Azure OpenAI を使う、と指定。要約にだけ使います |
| `AZURE_OPENAI_API_KEY` | Azure ポータルで発行したキー。空でも確認文までは出ます。要約だけ失敗します |
| `AZURE_OPENAI_ENDPOINT` | Azure OpenAI リソースの URL |
| `AZURE_OPENAI_DEPLOYMENT` | デプロイしたモデル名（例: `gpt-4o`） |
| `OPENAI_API_VERSION` | API の版。例のままでよいことが多い |
| `HEEDS_EXE` | `HEEDSMDO.exe` の場所（自分の PC の実パスに変更） |
| `HEEDS_PROJECT_PATH` | 使う `.heeds` ファイルの場所（自分の実パスに変更） |
| `HEEDS_TIMEOUT_SEC` | HEEDS 実行を待つ秒数。長い解析なら増やす |

- パスは `C:/...` のように **スラッシュ `/`** で書くのが無難です
- Study の画面名は `heeds/catalog.yaml` の `heeds_name` が既定です。この PC だけ違うときだけ `HEEDS_STUDY_STRESS=実際の名前` のように書きます。意味は [03_変数と設定.md](03_変数と設定.md)
- HEEDS のつなぎ方の詳細は [05_HEEDS接続.md](05_HEEDS接続.md)
- 上の `HEEDS_PROJECT_PATH` の例は、このフォルダに `HEEDS_PROJECT` を作った場合です。ファイルが別の場所なら、そのフルパスにします

チャットの前に、プログラム設定と HEEDS の実名が一致するか確認できます（解析はしません）。手順は [07_設定チェック.md](07_設定チェック.md) です。

```powershell
.\.venv\Scripts\python.exe check_heeds_project.py
```

または `check_heeds.bat` をダブルクリック。

ここまで終わったら [動かし方.md](動かし方.md) でチャットを開きます。

## つまずき

| 症状 | 対処 |
| --- | --- |
| コマンドが動かない／変なエラー | **コマンドプロンプトではなく PowerShell** で実行しているか確認 |
| `py -3.12` が無い / 別の Python で venv を作ってしまった | `py -0p` で 3.12 があるか確認。venv 作成は **`py -3.12 -m venv .venv`**。以降のコマンドは `.\.venv\Scripts\python.exe` |
| `ModuleNotFoundError` | 同じ python.exe で `pip install -r requirements.txt` |
| API 認証エラー | `.env` の場所・変数名・キーを確認（[03_変数と設定.md](03_変数と設定.md)）。確認文まではキーが無くても出ます |

起動したあとの画面や試験選択のつまずきは [動かし方.md](動かし方.md) の「つまずき」です。
